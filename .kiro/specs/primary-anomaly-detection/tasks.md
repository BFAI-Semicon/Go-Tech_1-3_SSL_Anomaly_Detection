## 3. スコア算出

- [x] 3.1 k 近傍距離から次元非依存の異常スコアを算出する
  - パッチごとに近傍探索口を 1 回呼び、取得距離の平均をコサイン距離の上限 2 で割って `[0, 1]` へ写す
  - 件数不足の判定はフォールバック後の距離列に対して行い、1 パッチでも近傍数が指定 k 未満なら要求 k と実件数を持つ型付き例外を送出し、以降のスコアを返さない
  - 各パッチのフォールバック有無の論理和をスコア配列と組にして返す。抽出器同一性は引数を素通しし、自前では保持しない
  - 完了時: 参照可能件数 `k-1` で型付き例外になり、ドメイン指定 0 件・プール `k` 件の偽探索口では例外にならずフォールバック有が true になることがテストで確認できる
  - _Requirements:_ 1.1, 1.2, 1.3, 1.4, 3.4, 6.4, 9.5
  - _Boundary:_ KnnScorer
  - _Depends:_ 2.1

- [x] 3.2 正常特徴から分布を推定し Mahalanobis 距離スコアを算出する
  - 較正は件数・和ベクトル・スキャッタ・Cholesky 因子の十分統計量だけを保持し、元特徴配列は保持しない。平均・共分散・埋め込み次元・正常件数は統計量から導く
  - 受けた特徴は行ごとに L2 正規化してから積む。ノルム 0 の行は値エラーとし、十分統計量を更新しない。件数不足または分解失敗は型付き例外とする。リッジ項は加えない
  - 距離は三角行列で解き、`d / (d + sqrt(D))` で `[0, 1)` へ写す。追加分の再較正は統計量加算であり、全件一括較正と同一の平均・共分散になる
  - ドメイン別較正の引き当ては完全一致のみ。該当鍵なしと未指定はプール較正を返し、前者だけフォールバック有にする
  - 完了時: 未正規化入力と正規化済み入力の較正が一致し、再較正が全件一括と同一距離を返し、`N = D` とノルム 0 行が拒否され、スコアが十分統計量だけから計算できることがテストで確認できる
  - _Requirements:_ 2.1, 2.2, 2.3, 2.4, 3.4, 6.2, 6.4
  - _Boundary:_ MahalanobisCalibration, MahalanobisCalibrationSet
  - _Depends:_ 2.1

- [x] 3.3 正規化済みスコアを重み付き融合する
  - 融合は重み付き平均とする。走査順はスコア方式の宣言順に固定し、加算順を決定的にする
  - 有効方式が 1 つのときは当該方式の正規化スコアそのものを返す
  - 完了時: 単一方式で入力スコアと一致し、2 方式で重み比が反映されることがテストで確認できる
  - _Requirements:_ 1.4, 3.2, 3.3, 3.6
  - _Boundary:_ ScoreFusion
  - _Depends:_ 2.1

## 4. 局在化

- [x] 4.1 パッチスコアを元画像と同じ画素格子へ合成する
  - 画素格子はパッチ位置とストライドから復元する。各パッチはストライド正方形へ寄与し、重なり画素は寄与の算術平均とする
  - 加算値と寄与回数を別配列に積み最後に除算し、パッチ走査順に依存しない
  - 完了時: 重なりあり配置で入力順を入れ替えても同一ヒートマップになり、復元形状が元画像の縦横と一致することがテストで確認できる

  - _Boundary:_ HeatmapComposer
  - _Depends:_ 2.1

- [x] 4.2 分位点基準で ROI 候補を切り出す

  - 連結成分は 8 近傍で求め、外接矩形と成分内最大スコアを持つ。代表スコア降順、同点は位置昇順で整列してから件数上限で打ち切り、先頭から 1 始まりの識別子を振る
  - 完了時: 定数入力が空一覧になり、降順採番と件数打ち切りがテストで確認できる
  - _Requirements:_ 3.5, 5.1, 5.2, 5.3, 5.4, 5.5
  - _Boundary:_ RoiExtractor
  - _Depends:_ 2.1

## 5. 近傍適合と検出合成

- [x] 5.1 正常メモリバンクを近傍探索口へ適合する

- [x] 5.2 スコア方式の選択・融合・局在化を合成して検出結果を返す

  - ヒートマップのストライドは入力同一性から取る。算出根拠に方式と重み、近傍数、正常件数、要求鍵、フォールバック有、同一性を載せる。無効方式に対応する件数欄は空にする
  - 完了時: 同一入力の 2 回実行が完全一致し、同一性不一致が Mahalanobis 単独でもスコアを返さず、不一致がノルム 0 より先に送出され、ドメイン非対称でも要求鍵とフォールバック有が分かれ、ドメイン不一致パッチの ROI が除外されないことがテストで確認できる
