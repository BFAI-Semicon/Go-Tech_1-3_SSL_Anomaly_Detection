# 令和8年度 進捗

各課題番号について、今年度の計画をステップに分解し、現在の状態
（作業済・作業中・未作業）を示す。

## 【１－２】欠陥箇所の可視化機能の設計

昨年度試作した「欠陥箇所を色で示す表示機能」を、実用レベルに仕上げる。

| ステップ | 内容 | 状態 |
| --- | --- | --- |
| 1. 要件定義 | 追加する処理（表示をなめらかに整える・ノイズ除去・欠陥箇所の自動判定）の要件を整理 | 作業済 |
| 2. 設計 | 各処理の方式を設計 | 作業中 |
| 3. 実装 | 表示機能への組み込み | 未作業 |
| 4. テスト | 見やすさと判定精度の確認 | 未作業 |

## 【１－３】自己教師あり学習に基づく異常判定機能の設計

正常品の画像だけからAIが自力で特徴を学ぶ方式で、欠陥品データが少なくても
高精度な異常判定を実現する。

| ステップ | 内容 | 状態 |
| --- | --- | --- |
| 1. 要件定義 | 方式の調査・比較と採用手法の決定 | 作業済 |
| 2. 設計 | 主要機能（特徴抽出、異常判定、検査員の知見を反映するフィードバック機能）の設計文書作成 | 作業中 |
| 3. 実装 | 設計に基づく開発 | 未作業 |
| 4. テスト・評価 | 判定精度とフィードバック効果の検証 | 未作業 |

## 【２－１】画像認識モデルの学習

昨年度に引き続き、モデルに対する学習を継続する。

| ステップ | 内容 | 状態 |
| --- | --- | --- |
| 1. 要件定義 | 昨年度の評価結果を踏まえ、軽量化の方針（蒸留の採用）を決定 | 作業済 |
| 2. 学習環境の整備と基準モデルの学習 | 実験をやり直せる環境を整え、蒸留の元となるモデルを学習 | 作業中 |
| 3. 軽量化モデルの設計・実装 | 蒸留による小型モデルの開発 | 未作業 |
| 4. 学習・調整 | 検証用装置を用いた学習と最終調整 | 未作業 |

## 【２－２】画像認識モデルのプログラム評価

開発したモデルの検出精度・処理速度・メモリ使用量をテストし、
年度目標（検出精度99%）の達成を確認する。

| ステップ | 内容 | 状態 |
| --- | --- | --- |
| 1. 評価方法の要件定義 | 測定する指標（精度・速度・メモリ使用量）と評価手順を決定 | 作業済 |
| 2. 評価用プログラムの実装 | 指標を統一的に測定する仕組みの整備 | 作業中 |
| 3. モデルのテスト | 検出精度・処理速度・メモリ使用量を測定し検証 | 未作業 |
| 4. 評価まとめ | 目標精度への到達状況と評価結果を整理 | 未作業 |
