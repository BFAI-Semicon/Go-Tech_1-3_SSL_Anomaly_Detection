# 令和8年度 進捗

各課題番号について、今年度の計画をステップに分解し、現在の状態
（作業済・作業中・未作業）を示す。

## 【１－２】欠陥箇所の可視化機能の設計

昨年度試作した「欠陥箇所を色で示す表示機能」を、実用レベルに仕上げる。

| ステップ    | 内容                                                                     | 状態   |
| ----------- | ------------------------------------------------------------------------ | ------ |
| 1. 基本設計 | 追加する機能と処理方式を決定                                             | 作業済 |
| 2. 詳細設計 | 表示の平滑化・ノイズ除去・欠陥箇所の自動判定について、具体的な処理を設計 | 作業中 |
| 3. 実装     | 表示機能への組み込み                                                     | 未作業 |
| 4. テスト   | 見やすさと判定精度の確認                                                 | 未作業 |

## 【１－３】自己教師あり学習に基づく異常判定機能の設計

正常品の画像だけからAIが自力で特徴を学ぶ方式で、欠陥品データが少なくても
高精度な異常判定を実現する。

| ステップ        | 内容                                                               | 状態   |
| --------------- | ------------------------------------------------------------------ | ------ |
| 1. 基本設計     | 方式を調査・比較し、採用する構成を決定                             | 作業済 |
| 2. 詳細設計     | 特徴抽出、異常判定、検査員の知見を反映するフィードバック機能を設計 | 作業中 |
| 3. 実装         | 設計に基づく開発                                                   | 未作業 |
| 4. テスト・評価 | 判定精度とフィードバック効果の検証                                 | 未作業 |

## 【２－１】画像認識モデルの学習

昨年度に引き続き、モデルに対する学習を継続する。（名工大）

| ステップ    | 内容                                             | 状態   |
| ----------- | ------------------------------------------------ | ------ |
| 1. 方針決定 | 昨年度の評価結果を踏まえ、今年度の学習方針を決定 | 作業済 |
| 2. 環境整備 | モデルの学習に必要な環境を整備                   | 作業済 |
| 3. 学習     | 検証用装置を用いてモデルを学習・調整             | 作業中 |
| 4. 検証     | 学習したモデルの性能を確認                       | 未作業 |

## 【２－２】画像認識モデルのプログラム評価

開発したモデルの検出精度・処理速度・メモリ使用量をテストし、
年度目標（検出精度99%）の達成を確認する。

| ステップ                | 内容                                                     | 状態   |
| ----------------------- | -------------------------------------------------------- | ------ |
| 1. 評価方法の設計       | 測定する指標（精度・速度・メモリ使用量）と評価手順を決定 | 作業済 |
| 2. 評価プログラムの実装 | 指標を統一的に測定する仕組みを整備                       | 作業中 |
| 3. テスト               | 検出精度・処理速度・メモリ使用量を測定し検証             | 未作業 |
| 4. 評価結果の整理       | 目標精度への到達状況と評価結果を整理                     | 未作業 |
